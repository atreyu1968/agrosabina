---
name: Elección del importador antes de extraer datos
description: El usuario debe ver el original y elegir su tipo antes de importar; ampliar mediante importadores específicos.
---

Mostrar el documento original y exigir que el usuario seleccione el tipo antes de extraer o importar sus datos. Cada tipo debe tener su revisión específica; cambiar de importador exige volver a leer el original, sin arrastrar datos especializados del anterior.

**Why:** el usuario pidió «ver el documento y seleccionar el tipo antes de importar» para evitar accidentes y poder añadir más importadores específicos.

**How to apply:** aplicar el mismo recorrido a archivos, adjuntos, texto pegado y correos. La IA puede avisar de discrepancias, pero no cambiar el tipo elegido silenciosamente. Las ampliaciones deben integrarse con los importadores existentes, no crear un flujo automático alternativo.

En los correos, importar los archivos adjuntos, no el asunto ni el cuerpo como si fueran el documento contable. Si faltan los bytes del adjunto, pedir recuperar el original; nunca sustituirlo silenciosamente por el texto del mensaje.

**Why:** el usuario advirtió que leer los correos en lugar de los adjuntos producía importaciones incorrectas.
